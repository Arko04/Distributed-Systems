--------------------------------------------------------------------------------
ANALYSIS
--------------------------------------------------------------------------------
EVENTUAL CONSISTENCY (AP System):

Advantages:
  ✅ System remained available for writes (2/3 nodes)
  ✅ Fast write response (no waiting for failed node)
  ✅ Remaining replicas stayed synchronized

Disadvantages:
  ❌ Failed replica missed updates (data loss risk)
  ❌ No automatic catch-up when replica recovers
  ❌ Requires additional mechanisms for full recovery

Real-world solutions:
  - Hinted Handoff: Another node saves updates for the failed node
  - Read Repair: Detect and fix inconsistencies on read
  - Anti-Entropy: Background process to sync all replicas
