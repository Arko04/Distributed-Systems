Conflict Resolution Strategy: Last-Write-Wins (LWW)
  - Compares timestamps when versions are equal
  - Higher timestamp wins
  - All replicas use the same rule (deterministic)
  - Losing value is silently discarded

--------------------------------------------------------------------------------
ANALYSIS
--------------------------------------------------------------------------------

LAST-WRITE-WINS (LWW) EVALUATION:

Advantages:
  ✅ Simple to implement
  ✅ Deterministic (same result on all replicas)
  ✅ Automatic (no human intervention needed)
  ✅ Convergent (system stabilizes quickly)

Disadvantages:
  ❌ Silent data loss (losing value disappears)
  ❌ Not suitable for all data types (counters, lists)
  ❌ Relies on synchronized clocks
  ❌ Last writer may not have seen the first write

BETTER ALTERNATIVES FOR SOME USE CASES:
  - CRDTs (Conflict-free Replicated Data Types): Auto-merge
  - Multi-Version: Keep both values, let application decide
  - Operational Transform: For collaborative editing
