================================================================================
SCENARIO 1: TEMPORARY INCONSISTENCY OBSERVATION
================================================================================
Date: Sat Jun  6 04:44:50 +0330 2026
Consistency Model: eventual
Network Delay: 500ms

--------------------------------------------------------------------------------
OBJECTIVE
--------------------------------------------------------------------------------
Demonstrate that in eventual consistency mode, a read immediately after
a write to a different replica may return stale or missing data.

--------------------------------------------------------------------------------
STEPS
--------------------------------------------------------------------------------
1. Write x=10 to Replica 1
2. Immediately read x from Replica 2
3. Wait for replication to complete
4. Read x from Replica 2 again
5. Check all replicas

--------------------------------------------------------------------------------
RESULTS
--------------------------------------------------------------------------------

--- Step 1: PUT x=10 to Replica 1 ---
PUT Latency: 30ms
Response: {"success":true,"message":"Value stored successfully","version":1,"updated_by":"replica1"}

--- Step 2: Immediate GET from Replica 2 ---
GET Latency: 29ms
Response: {"key":"x","value":"","version":0,"updated_by":"","timestamp":0,"found":false}
STALE READ: Yes (value not yet propagated)

--- Step 3: Waiting for convergence ---
Convergence Time: .5s

--- Step 4: Final state across all replicas ---

Replica 1:
{
    "key": "x",
    "value": "10",
    "version": 1,
    "updated_by": "replica1",
    "timestamp": 1780708490489250000,
    "found": true
}

Replica 2:
{
    "key": "x",
    "value": "10",
    "version": 1,
    "updated_by": "replica1",
    "timestamp": 1780708490489250000,
    "found": true
}

Replica 3:
{
    "key": "x",
    "value": "10",
    "version": 1,
    "updated_by": "replica1",
    "timestamp": 1780708490489250000,
    "found": true
}

--------------------------------------------------------------------------------
ANALYSIS
--------------------------------------------------------------------------------
With eventual consistency and 500ms delay:
- The PUT returned immediately (fast write)
- Replica 2 may have returned stale data if read before replication completed
- All replicas eventually converged to the same value
- Convergence time depends on network delay + processing time
